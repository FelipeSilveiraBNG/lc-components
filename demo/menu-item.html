Menu Item

<lc-menu-item> — item de menu do Dropdown. Não se usa sozinho: é filho de um <lc-dropdown>, como <option> é de <select>.

Ênfase, ícone e desabilitado

variant="danger" tinge o item destrutivo. disabled o tira da navegação por teclado. Um Icon antes do rótulo é só conteúdo — o item não tem slot próprio para ele.

value é o que chega no evento

O dropdown emite lc-select com { value, item }, e o value vem daqui. É o identificador estável do item — não dependa do texto do rótulo, que muda quando alguém reescreve a interface. 

document.addEventListener('lc-select', (e) => {
  console.log(e.detail.value); // 'editar', 'duplicar', 'excluir'
});

Era a última classe de que um componente dependia

Antes do ADR 0001, o lc-dropdown procurava por .lc-menu-item para achar o primeiro item e para descobrir qual foi acionado, e o CSS dele estilizava ::slotted(.lc-menu-item). Um componente dependia de uma classe que o autor da tela tinha de acertar de memória.

Com a tag, o dropdown procura por lc-menu-item. Um erro de digitação vira uma tag que não sobe — visível na hora — em vez de um item que existe na tela mas não responde ao clique.

Separador é <hr>

Para dividir grupos dentro do menu, um <hr> nativo entre os itens — não há componente de separador, e não precisa haver.
