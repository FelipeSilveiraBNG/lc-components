lc-modal comp

Diálogo sobre <dialog> nativo, com foco preso, fundo escuro e Esc de graça.

Abrir sem uma linha de JavaScript

data-lc-modal="open <id>" em qualquer elemento abre o modal daquele id; "close <id>" fecha. É o que permite protótipo navegável sem escrever script — e é convenção emprestada do Web Awesome.

Fechamento cancelável

Fecha pelo ×, pelo clique no fundo e por Esc. Os três passam pelo mesmo evento lc-hide, que é cancelável e diz a origem em detail.source — dá para impedir o fechamento quando há alteração não salva, sem precisar interceptar três caminhos diferentes. 

document.getElementById('m1').addEventListener('lc-hide', (e) => {
  // Deixa o × fechar sempre; barra fundo e Esc se houver alteração.
  if (e.detail.source !== 'close-button' && temAlteracao) e.preventDefault();
});

Atributos e medidas

size="small|large", without-header, without-footer e without-close-button. Para largura fora da escala, as custom properties --width e --max-height — nunca reestilizando por dentro.

O modal aberto tem um lc-dropdown dentro. Abra os dois: o menu não é recortado pelo diálogo, porque os dois estão no top layer. No legado isso exigia z-index e ainda quebrava.
