Input

<lc-input> — campo de texto de uma linha, e dono do próprio rótulo. Divide a base lc-campo com Select e Textarea: mesma altura, mesmo raio, mesmas regras de erro.

Rótulo e erro

O erro vem da validação nativa — required, type, pattern — e não de uma classe que o autor acrescenta. O rótulo é <label> de verdade, com for — sem isso o clique no texto não foca o campo e o leitor de tela não anuncia nada.

Dica e desabilitado

O atributo hint é a mensagem neutra, para o que não é erro — some quando uma mensagem de validação toma o lugar dela.

Tamanho compacto

size="small" existe por causa de uma tela real: a linha de filtro no cabeçalho das tabelas do painel, onde o campo tem de caber na altura da célula. Vale para os três campos — lc-input, lc-select e lc-textarea.
