lc-dropdown comp

Menu de ações que abre no top layer nativo. Fecha por clique fora e por Esc sozinho, sem uma linha de configuração.

Menu básico

O gatilho vai no slot="trigger"; os itens são .lc-menu-item soltos. data-variant="danger" tinge o item destrutivo, e <hr> separa grupos.

Posicionamento

placement aceita bottom-start (default), bottom-end, top-start e top-end.

O painel abre no top layer nativo: não é recortado por contêiner com overflow, funciona dentro de modal e na última linha de tabela que rola, sem z-index. Era o bug estrutural nº 1 do legado.

Evento cancelável

Emite lc-select com { value, item }. É cancelável: preventDefault() mantém o menu aberto — útil para item que alterna algo sem fechar. 

document.addEventListener('lc-select', (e) => {
  if (e.detail.value === 'colunas') e.preventDefault(); // mantém aberto
  console.log(e.detail.value);
});
