lc-switch

Interruptor que é cidadão do <form> nativo: entra no FormData, responde a reset() e participa da validação.

Dentro de um formulário

Desligado não entra no FormData — igual ao checkbox nativo, e não um false. Mexa nos interruptores e veja a saída mudar; o Reset volta ao estado que os atributos declaravam.

Ser form-associated é o que separa este componente de uma div com aparência de interruptor: o protótipo pode enviar o formulário de verdade e você vê os dados que o backend receberia.

Evento

Emite lc-change com { checked, value } em detail. O evento borbulha e atravessa o shadow boundary, então dá para escutar no document ou no <form>. 

document.addEventListener('lc-change', (e) => {
  console.log(e.detail.checked, e.detail.value);
});
