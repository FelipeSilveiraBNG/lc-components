lc-components

Kit de web components do BNG LinkCare para protótipos — sem build, sem dependência de runtime, só HTML. Dezenove componentes, em dois temas que trocam por atributo.

Cada componente é uma tag <lc-*> encapsulada em Shadow DOM, estilizada por design tokens (--lc-*) e com API inspirada no Web Awesome: eixos variant, appearance e size, slots nomeados e participação nativa em <form>. Não existe classe de componente, não existe build e não existe dependência de runtime — o kit é HTML, CSS e ES modules.

O que o distingue: dois temas ao mesmo tempo

Os dois temas são carregados sempre, e trocar entre eles é mudar um atributo no <html> — sem recarregar nada. legacy reproduz o painel PHP (AdminLTE/BS3) e modern reproduz o console React (Tailwind/slate).

Nenhum componente muda de código quando o tema troca: o que muda é o valor dos tokens. Use o seletor no cabeçalho para alternar — nada nesta documentação foi escrito duas vezes, e é essa a demonstração.

Os dois temas são reprodução medida, não proposta de design. Nenhum valor neles foi inventado: cada um saiu do código do produto correspondente.

Comece por aqui

Uma linha de CSS e uma de JavaScript no <head>, e todas as tags <lc-*> ficam disponíveis: 

<html lang="pt-BR" data-lc-theme="legacy">
  <head>
    <link rel="stylesheet" href="lc.css" />
    <script type="module" src="components/loader.js"></script>
  </head>
  <body class="lc">
    <div class="lc-page-body">…</div>
  </body>
</html>

A página precisa ser servida por HTTP — ES modules não funcionam em file://. O caminho pelo CDN, a versão fixada e as duas armadilhas que pegam quem chega do legado estão em Instalação.

Um exemplo, renderizado aqui mesmo

Nenhuma das tags abaixo foi estilizada por esta página. Elas são o kit, rodando dentro da documentação do próprio kit — e trocam de tema junto com ela.

Os dezenove componentes

Uma tag, uma página — sem exceção. Cada uma traz os exemplos vivos e as decisões que valem saber; as receitas prontas para colar estão no AGENTS.md, na raiz do repositório.

Tag O que é Página
lc-alert Aviso em bloco, que interrompe a leitura Alert
lc-badge Chip de status — não é contador Badge
lc-button Botão, nos eixos de papel, aparência e tamanho Button
lc-button-group Botões emendados num controle segmentado Button Group
lc-card Contêiner com barra de acento no topo Card
lc-dropdown Menu de ações ancorado, aberto no top layer Dropdown
lc-icon Ícone resolvido por biblioteca registrável Icon
lc-input Campo de texto de uma linha, dono do próprio rótulo Input
lc-logo A marca BNG LinkCare, nas seis variantes Logo
lc-menu-item Item de menu do lc-dropdown Menu Item
lc-modal Diálogo sobre o <dialog> nativo Modal
lc-select Seleção de uma opção, sobre o <select> nativo Select
lc-sidebar A barra de navegação da aplicação Sidebar
lc-sidebar-group Grupo com submenu, dentro da barra Sidebar Group
lc-sidebar-item Uma linha que navega, dentro da barra Sidebar Item
lc-sidebar-label Rótulo de seção. Só texto Sidebar Label
lc-switch Interruptor liga/desliga. Entra no FormData nativo Switch
lc-textarea Campo de texto de várias linhas Textarea
lc-toast Região de notificações, normalmente via toast() Toast
Tabela é a única exceção, e continua sendo classe: <table class="lc-table">. O parser HTML expulsa elemento desconhecido de dentro de <table>, então <lc-row> viraria irmão da tabela e a tabela ficaria vazia. Detalhes em Tabela — e o índice logo acima é feito exatamente disso.
