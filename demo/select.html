Select

<lc-select> — seleção de uma opção, sobre o <select> nativo. Divide a base lc-campo com Input e Textarea.

As opções são <option>

Nada de API nova para a lista: os <option> vão escritos como filhos, do jeito que já se escreve HTML. O rótulo é atributo, porque o controle é dono do próprio rótulo.

Obrigatório e desabilitado

O erro vem da validação nativa, como nos outros campos — não existe atributo error. Para regra de negócio, use setCustomValidity().

Tamanho compacto

size="small" para a linha de filtro no cabeçalho das tabelas, onde o campo tem de caber na altura da célula.

Por que as opções são copiadas, e não slotadas

O <select> nativo só aceita <option> e <optgroup> como filhos: um <slot> lá dentro não é conteúdo válido e o navegador simplesmente o descarta. Então o componente lê os <option> do light DOM e os clona para dentro do <select> do shadow root.

Os originais não aparecem duas vezes porque não há slot para eles — filho de light DOM sem slot correspondente não é renderizado. Um MutationObserver mantém a cópia em dia, então protótipo que popula a lista por script continua funcionando.

A alternativa seria escrever um listbox próprio, como o wa-select faz. Custa muito mais e perde o seletor nativo do celular — que num protótipo de escala ou plantão é justamente o que se quer mostrar.
