Eventos

Todos borbulham e atravessam o shadow boundary — pode escutar no document.

Tabela

Evento Origem detail
lc-change lc-switch { checked, value }
lc-select lc-dropdown — cancelável, mantém aberto { value, item }
lc-show / lc-after-show lc-modal, lc-dropdown —
lc-hide / lc-after-hide lc-modal, lc-dropdown — lc-hide cancelável { source }

Por que atravessar o shadow boundary importa

Um evento que não atravessa obriga quem escuta a alcançar o elemento por dentro do shadow root — que é exatamente o que a regra de ouro nº 2 proíbe. Emitindo com composed, o listener no document basta, e o protótipo não precisa conhecer a estrutura interna de nada. 

// Um listener para todos os menus da página.
document.addEventListener('lc-select', (e) => {
  console.log('ação:', e.detail.value);
});

Cancelável é o que salva o protótipo

lc-select e lc-hide são canceláveis. O segundo diz a origem em detail.source, então dá para tratar × diferente de Esc e de clique no fundo com um só listener — em vez de interceptar três caminhos e esquecer um. 

modal.addEventListener('lc-hide', (e) => {
  if (e.detail.source !== 'close-button' && temAlteracao) e.preventDefault();
});
