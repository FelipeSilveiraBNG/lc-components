Todo token existe nos dois temas — o tools/check-contrato.mjs reprova se não. Um token que só um tema define é um buraco que aparece meses depois, na tela que ninguém estava olhando.

As três camadas

Primitivos (tokens/primitivos.css) são escalas cruas, com nome privado --lc-_*. Os arquivos de tema são os únicos que podem ler daqui — o que não quer dizer que todo primitivo esteja sendo lido. Os da marca, logo abaixo, não estão.

Contrato (styles/temas/*.css) é o conjunto de nomes que os componentes leem. Cada tema define o contrato inteiro.

Consumo (styles/native.css e os componentes) só lê contrato, nunca primitivo. O check-contrato.mjs reprova quem furar essa separação nos dois sentidos.

Os primitivos da marca

Estes são a identidade do brandbook, que é a do tema modern — o lado React do produto. Estão no repositório e nenhum tema os lê ainda: o modern hoje reproduz o console admin em slate e blue-600. A classificação está resolvida, a adoção não.

Primitivo Valor · contraste no branco Papel que ele pode ter

Esta tabela não muda quando você troca o tema, e a de cima muda. Não é descuido: é a diferença entre as duas camadas ficando visível. Primitivo é valor cru, igual em qualquer tema; contrato é o que cada tema decide.

A coluna de contraste é o que impede a leitura ingênua do brandbook. O turquesa é a cor de destaque dele, mas com 1,74:1 no branco reprova como texto e como borda de 1px — e branco em cima dele também. Ele é cor de superfície. Quem resolve os outros dois papéis são navy-deep (9,98:1 sobre o turquesa) e teal-ink (4,97:1 como texto no branco), e essas duas vêm do app linkcare-me, não do brandbook.

Nomes por papel, não por aparência

--lc-radius-control, não --lc-radius-4px. --lc-color-brand-fill-loud, não --lc-color-azul-escuro. O nome diz onde a coisa é usada, então continua verdadeiro quando o valor muda de tema para tema.

Os papéis de cor: fill-quiet (fundo tintado), fill-normal (preenchimento sólido), fill-loud (o sólido em hover), on-loud (texto sobre o sólido), border e text — a cor escurecida o bastante para ser legível como texto.
